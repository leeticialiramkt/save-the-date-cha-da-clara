# Save the Date · Chá de Bebê da Clara 🌼

Landing page estática (HTML/CSS/JS puro, sem build).

- Envelope animado de abertura, pétalas caindo, revelação ao rolar
- Contagem regressiva para 07/11/2026 às 14h (horário de Brasília)
- Polaroids com fotos da família, botão de confirmação no WhatsApp, Google Agenda, arquivo .ics e rota no mapa

## Publicar na Vercel
1. Em vercel.com → **Add New… → Project** → importe este repositório.
2. Framework Preset: **Other**. Sem comando de build. Output: raiz (`.`).
3. Deploy. A cada `git push` a Vercel publica de novo.

Para a pré-visualização bonita no WhatsApp, troque o `og:image` do `index.html` pelo endereço completo (ex.: `https://SEU-SITE.vercel.app/img/og.jpg`).
